# nigiwai-plugins

[nigiwai（賑わい）](https://nigiwai.info) に、サーバーの人数などを送るプラグインの配布場所です。

- 送る内容：現在の人数、最大人数、TPS、稼働時間、プレイヤー名。IP アドレスやチャットは送りません。
- サーバーごとの API キーは、nigiwai の管理画面で発行し、各サーバーの設定ファイルに入れます。このリポジトリにも、プラグインの jar にも、キーは含まれません。
- jar は [Releases](../../releases) からダウンロードできます。

nigiwai は Minecraft の公式サービスではありません。
